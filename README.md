#descripcion del proyecto 
simulacion de una estacion de tren que implimenta las tres fases solicitadas para el corte parcial
1 fase(bufer dinamico)
registrar usuarios,gestionar reportes y para pasar tarjeta
fase 2(lista enlazada)
almacenar y mostrar el historial de tarjitas
fase 3 (cola y pila)
hacer fila,llama a la siguiente persona,deshacer registro

##archivos del proyecto
-main.c
codigo fuerte completa con comentarios
-readme.md
documentacion parcial para corte parcial
##copilacion y ejecucion
1-abrir main.c y ejecutar
2-copilar y ejecutar
3-seleccionar opcion desde el menu principal
4-opcion 0 para salir y liberar toda la memoria 
##liberacion de memoria
al seleccionar la opcion 0 se ejecuta fee() para el arreglo dinamico y se recorre la lista anlazada liberando cada nodo, evitando fugas de memoria
